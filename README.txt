V6 完成
- 点击设备/车辆打开可收起的现场对象卡，显示真实模拟来源和关联任务。
- 手动旋转接管镜头；恢复流程跟随明确回到当前作业镜头。
- 标签射线遮挡、边缘提示与卡片避让；暂停状态下也完成有限遮挡确认。
- 自动/精细/均衡/流畅画质，细节按距离分级，重复构件合批。
- 精修搅拌车轮胎、轮毂、翼子板、驾驶室和后部卸料机构。
- 溜槽与液压按绝对业务时间展开、对接和收回，支持暂停/回看/倍速。
- 装载机铲入取料，料堆局部缺口、斗料与接收仓同步。
- 主楼称量斗填料、闸门放料、双轴混合、双开卸料门与近景螺旋叶片。
- 生产图分开显示骨料、粉料、水与外加剂，并可定位内部机构。
- 地磅移至入口直线通道，齐平台面接地；满载过磅、空车复磅及离场前进通行。
- 碎石卸料车道保留整车空间，集料带下穿齐平承重盖板；粉料车绕开砂石仓棚。
- 返站进入洗车区时自动切换专用3D跟随镜头，完成后保留洗车画面。

完整流程
厂家→到站→登记/过磅/验收→指定仓卸料→复磅入库→生产供料。
砂石储料仓→装载机→自动配料仓→集料/斜皮带→称量→搅拌。
水泥/粉煤灰筒仓位于生产楼旁；罐车气力入仓，螺旋供料进入称量斗。
配方/试配/确认→生产→装车→站外配送→工地泵送→签收→返站→洗车。
三地点模型轮廓入口保留任务进度；运输图按任务显示对应车辆形状。

本地开发
修改源码、运行开发服务器或执行验证时，使用 Node.js 22 或以上并运行下列命令。
npm install
npm run dev
npm run build
npm test
npm run test:glb

models/ready-mix-plant-v6.glb 是实际导出的全区域静态模型，保留几何、材质和导出时姿态。
交互与业务动画在网页源码中。导出当前场景可通过设置面板操作。

所有业务数据来自本地模拟或明确标注的快照。未接入 PLC、GPS、地磅及料位传感器。
路线与时长示意化；试配不代表真实质量检验。性能须结合设备、视角和画布尺寸阅读。
许可待作者选择。详细说明见 README.md。
